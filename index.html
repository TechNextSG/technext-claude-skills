How skills work

Four things to know.

Claude picks them upWhen a request matches a skill’s description, Claude reads the skill first. Type /name to call one directly. Skills marked “manual” only run when called.
Install a TechNext skillEvery skill has its own GitHub repo: git clone it into ~/.claude/skills/<name> and git pull to update. Or download the .zip and unzip it into ~/.claude/skills (Windows: C:\Users\<you>\.claude\skills), or copy the install command. Then restart Claude Code.
Kept up to dateAfter every job, Claude adds what it learned to the skill’s lessons log and rules, then tools/build_skills.py --push updates its repo and this page. It runs by itself whenever a skill changes.
Add a new skillPut its folder in ~/.claude/skills, add its name to OWN in the build script, run it and push. Big render caches (like nexi-cam) stay on the PC and are left out of the zip.
